## ~/ projects

### 01 — AI Resume Analyzer

[View Repository](https://github.com/karthikSBidarkundi15/resume-analyzer-ai)

An AI-powered resume analysis application that generates role-aware feedback, ATS scores, missing keywords, and improved resume bullet points.

- Generates structured JSON feedback for a selected target role.
- Provides downloadable PDF reports and visual score gauges.
- Deployed using Streamlit Community Cloud.

`Python` `Streamlit` `Groq API` `Plotly` `ReportLab`

### 02 — Gram Yatra

[View Repository](https://github.com/karthikSBidarkundi15/gram-yatra)

A public transport tracking system designed for small cities.

- Tracks public transport locations in real time.
- Includes an SMS fallback for low-connectivity areas.
- Combines GPS/IoT concepts with mobile and web technologies.

`Python` `GPS` `IoT` `Mobile/Web`

### 03 — AI-Based Interview Training & Proctoring System

[View Repository](https://github.com/karthikSBidarkundi15/AI-Based-Interview-Training-and-Proctoring-System)

An interview simulation platform that combines AI-based interview preparation and online proctoring.

- Generates resume-based interview questions.
- Analyzes interview performance and emotions.
- Uses face and eye tracking for proctoring.

`Python` `Computer Vision` `AI`

### 04 — Smart Emergency Vehicle Priority System

[View Repository](https://github.com/karthikSBidarkundi15/Smart-Emergency-Vehicle-Priority-System-Using-AI)

An ongoing computer vision project designed to detect emergency vehicles and dynamically prioritize traffic signals.

`Python` `Computer Vision` `AI`

### 05 — AI-Powered Multi-Interview Simulator

[View Repository](https://github.com/karthikSBidarkundi15/Ai-multi-interview-simulator)

A conversational AI platform that simulates role-based interview rounds and provides real-time feedback.

- Supports multiple interview rounds.
- Provides feedback during interview practice.
- Uses a modular architecture.

`Python` `Conversational AI` `LLMs`

### 06 — Face Mask Detection

[View Repository](https://github.com/karthikSBidarkundi15/face-mask-detection)

A real-time face mask detection system using live video processing and a CNN-based deep learning model.

- Processes video using OpenCV.
- Uses a CNN-based model to classify mask and no-mask cases.

`Python` `OpenCV` `CNN` `Deep Learning`
